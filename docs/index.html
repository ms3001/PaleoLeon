PaleoLeon

A small, local web dashboard for a hedge fund using Interactive Brokers and thinkorswim / Schwab.

Download

One-click launchers. Unzip, then double-click. The first run takes about 30 seconds to set up; later runs are instant.

Mac Windows Linux

On macOS, right-click the file → Open the first time to bypass Gatekeeper.
On Windows, click More info → Run anyway if SmartScreen warns.
You'll still need IB Gateway running locally with API access enabled.

What it does

  • Connects to your local IB Gateway via the TWS API and reads every sub-account under your Financial Advisor master login.
  • Shows a firm-wide summary: NAV, cash, unrealized & realized PnL, top positions, exposure by asset class.
  • Drill into any individual sub-account for a full position list with % of NAV.
  • Looks up live quotes from Schwab (formerly thinkorswim) for any symbol.

Run from source (advanced)

If you'd rather not use the one-click launcher:

# 1. Install
pip install git+https://github.com/ms3001/PaleoLeon.git

# 2. Start IB Gateway (paper port 4002 by default) and log in
#    Enable: Configure → Settings → API → Enable ActiveX and Socket Clients

# 3. Launch the dashboard
paleoleon

Open dashboard (localhost:8000) View source

The button works only after you've launched the dashboard.

Configuration

Environment variables (all optional):

VariableDefaultPurpose
PALEOLEON_IB_HOST127.0.0.1IB Gateway host
PALEOLEON_IB_PORT40024001 live · 4002 paper · 7497 TWS paper · 7496 TWS live
PALEOLEON_IB_CLIENT_ID17Any unused TWS client id
PALEOLEON_PORT8000Dashboard port
PALEOLEON_REFRESH_SECONDS15How often the dashboard polls itself

Account labels and Schwab credentials live in ~/.paleoleon/settings.json.

Schwab / thinkorswim quotes

  1. Register an app at developer.schwab.com.
  2. Install the optional dep: pip install 'paleoleon[schwab] @ git+https://github.com/ms3001/paleoleon.git'
  3. Open /quote, paste the app key & secret, save. First quote lookup will trigger the OAuth browser flow once; the refresh token is then cached locally.
